# Product Radar Submission Draft

## Позиционирование

CaseCaption - продукт для настройки документных сценариев и выпуска связанных комплектов для SMB,
бухгалтеров и сервисных команд.

Это не “AI-документооборот” и не еще один генератор счета. Пользователь добавляет письмо, PDF/DOCX,
сохранённые данные или предыдущий выпуск, проверяет источники и расхождения, а затем выпускает комплект
по согласованным шаблонам компании.

## Короткий tagline

Комплект документов из одного проверенного ввода.

## Описание проекта

CaseCaption помогает убрать ручную пересборку связанных документов там, где данные уже есть в `1C`,
Excel, CRM, письмах или файлах, но человек всё равно переносит их в Word/Excel, проверяет совпадение
полей и исправляет возвраты.

Фокус не на “еще одном генераторе счетов”. CaseCaption берет один повторяемый процесс клиента:

`данные -> набор документов -> проверка -> пакет бухгалтеру/в учетный контур`

и превращает его в рабочий сценарий:

- выбранный пользователем набор шаблонов;
- исходники и проверенные данные по сделке/услуге;
- автозаполнение реквизитов по ИНН;
- единый проверенный набор значений для связанных документов;
- видимые источники, конфликты и значения, требующие подтверждения;
- выпуск договора, счета, акта, спецификации или другого состава документов;
- реестр/summary для бухгалтера;
- короткий audit trail и чек расхождений.

## Для кого

- Бухгалтерские аутсорсеры, которым клиенты присылают первичку и данные вразнобой.
- Частные бухгалтеры с несколькими SMB-клиентами.
- Небольшие B2B-сервисные компании, где менеджеры руками собирают счета, акты и договоры.

## Что показать

- Конструктор сценария: пользователь выбирает нужные документы.
- Сбор данных: письмо, PDF/DOCX, сохранённый набор или предыдущий выпуск.
- Проверка: источник каждого значения, конфликты и ручное подтверждение.
- Выпуск пакета: несколько документов, preview/download, summary и след действий.
- Карточка документа: результат, артефакты и история.

## Что уже есть

- Автозаполнение реквизитов по ИНН.
- Опросник по сценарию с ручным контролем полей.
- Shared payload для связанных документов.
- Генерация пакета документов.
- Предпросмотр и скачивание результата.
- Карточка документа, артефакты, история действий.
- Accounting summary / пакет для передачи дальше.

## Чего не обещать

- Не “замена 1C”.
- Не оператор ЭДО.
- Не full ECM/СЭД.
- Не generic AI-проверка договоров.
- Не “любой документ в любом формате”.
- Не полностью автоматическая настройка хаотичного DOCX без review.
