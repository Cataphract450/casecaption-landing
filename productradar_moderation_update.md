## Профиль основателя

Нужно сделать вручную в Product Radar, потому что требуется реальное фото.

Поля:

- Имя: `Игорь`
- Telegram: `@Igorigoryyy`
- Фото: реальное фото основателя
- О себе:

```text
Основатель CaseCaption. Делаю сервис для настройки и выпуска повторяемых документных сценариев из одного заполнения.
```

Если лимит 200 символов:

```text
Основатель CaseCaption. Делаю сервис для выпуска повторяемых пакетов документов из одного заполнения.
```

## Ответ модератору

```text
Дмитрий, спасибо. Обновил профиль основателя с фото и контактами, добавил вертикальные слайды 9:16 с ключевыми преимуществами продукта в галерею. Посмотрите, пожалуйста, теперь карточка должна соответствовать формату.
```

## Что проверить перед отправкой

- Карточка публикуется от лица профиля основателя, а не безличного аккаунта.
- В профиле есть фото и Telegram.
- В галерее не обычные горизонтальные скриншоты, а вертикальные слайды 9:16.
- Слайды одного размера: 1080x1920.
- Первый слайд сразу объясняет основной сценарий: пакет документов из одного заполнения.
