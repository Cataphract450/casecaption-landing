# CaseCaption Landing

Статический продуктовый лендинг для первых касаний, Product Radar и разговора о
платном пилоте.

Канонический первый экран:

```text
Договор, счёт и акт — без повторного переноса данных
```

Клиентский путь на странице:

1. конкретный результат и реальный интерфейс на первом экране;
2. полное демо основного рабочего пути на `2:11` без регистрации;
3. три факта синтетического контрольного прогона;
4. один путь: исходники → проверка → договор, счёт, акт и ZIP;
5. кому подходит и честные границы;
6. фиксированный платный пилот.

Текущий оффер:

- один повторяемый процесс;
- до трёх утверждённых шаблонов;
- настройка за `5` рабочих дней;
- `29 000 ₽`: `14 500 ₽` при старте и остаток после двух самостоятельных
  выпусков сотрудника клиента;
- до оплаты доступны только публичное демо и `12`-минутная проверка процесса;
- это слой подготовки до `1С` и ЭДО, а не их замена и не бухгалтерское или
  юридическое заключение.

Каноническая система формулировок находится в
[`docs/validation/commercial_copy_system_ru.md`](../docs/validation/commercial_copy_system_ru.md).

## Демо и доказательство

Публичные файлы:

- `assets/casecaption-demo-complete-flow-2026-08.mp4`;
- `assets/casecaption-demo-complete-flow-2026-08-poster.jpg`;
- `assets/casecaption-demo-complete-flow-2026-08-chapters.vtt`;
- `assets/casecaption-og-complete-flow-2026-08.jpg`.

Open Graph-превью воспроизводимо собирается из актуального первого экрана при
запущенном локальном сервере:

```powershell
node scripts/ops/render_landing_og.mjs
```

Видео длится `131,3` секунды, имеет размер `1600×900`, кодек H.264 и не содержит
звуковой дорожки. Оно показывает весь основной рабочий путь: выбор сценария,
письмо, DOCX и PDF, проверку значений по источникам, единые данные комплекта,
выпуск, ZIP, полный просмотр договора, счёта и акта и возврат к сохранённому
результату.

Подтверждённые факты записи:

- три настроенных шаблона и три исходника;
- `24` значения проверены перед выпуском: `23` приняты вместе, НДС — отдельно;
- ручной перенос значений не понадобился;
- на выходе — договор, счёт, акт и ZIP;
- каждый документ открыт и прокручен до физического конца страницы;
- внешний разбор выполнен реальной моделью без fallback.

Это технический прогон на синтетических данных, не клиентская статистика.

## Локальный просмотр

Из корня проекта:

```powershell
python -m http.server 4177 -d landing
```

Открыть `http://127.0.0.1:4177/`.

## Проверка

При запущенном локальном сервере:

```powershell
$env:PAGE_URL='http://127.0.0.1:4177/'
$env:QA_OUTPUT_DIR='.tmp/landing-commercial-qa/latest'
node scripts/ops/run_landing_qa.mjs
```

Скрипт проверяет `1440×900`, `1366×768`, `768×1024`, `390×844` и `320×700`:
идентичность страницы, видео, poster и главы, длительность полного демо, ссылки,
scope и цену, клавиатурный focus,
отсутствие горизонтального скролла, ошибок браузера и запрещённых обещаний. В папке
отчёта сохраняются `report.json` и снимки каждого размера.

Перед публикацией дополнительно выполнить:

```powershell
git diff --check -- landing scripts/ops/run_landing_qa.mjs
```

## Product Radar

Актуальная вертикальная галерея `1080×1920` находится в
`assets/productradar-current/`. Для загрузки готов архив
`assets/productradar-current/productradar-current-upload.zip`.

Пять слайдов последовательно показывают результат, прошлый выпуск и новые
источники, проверку изменений, готовый комплект и условия пилота. Все кадры взяты
из реального интерфейса на синтетических данных. Воспроизводимый исходник и команда
рендера находятся в `productradar-gallery/current/`.

## Публикация

Публичная версия живёт в отдельном репозитории
`Cataphract450/casecaption-landing`:

`https://cataphract450.github.io/casecaption-landing/`

Изменения в private-репозитории `LEX-FLOW-AI` сами этот URL не обновляют. Перед
отправкой ссылки клиенту нужно синхронизировать содержимое `landing/` с отдельным
публичным репозиторием, дождаться GitHub Pages и запустить live-smoke:

```powershell
$env:PAGE_URL='https://cataphract450.github.io/casecaption-landing/'
$env:LIVE_SMOKE='1'
$env:QA_OUTPUT_DIR='.tmp/landing-live-qa/<commit>'
node scripts/ops/run_landing_qa.mjs
```

- первый экран показывает результат, реальный интерфейс, срок, scope, цену и один
  очевидный путь к демо;

- числа `13`, `7` и `3 + ZIP` подписаны как синтетический технический прогон;
- нет обещаний заменить `1С`, CRM, ЭДО или эксперта;
- PDF/DOCX описаны как документы с текстовым слоем; OCR не обещан;
- бесплатно не предлагается работа с шаблонами или материалами клиента;
- цена, срок, оплата и критерий приёмки совпадают со всеми outreach-материалами;
- все Telegram-ссылки ведут на `@Igorigoryyy`;
- live-smoke публичного URL завершился без ошибок.
